# Generator provenance

`implementation.c` in the parent directory is generated by:

    cd dev_generators && python3 gen.py ../implementation.c

(pure python3+numpy; deterministic on this host — constants are baked as hex
doubles computed via numpy.longdouble, i.e. x87 80-bit on x86-64).

Structure:
- netlib.py   : split-complex straight-line DFT codelet emitters (2,3,4,5,8,9=CT3x3,
                PFA, CT, folded odd/prime DFTs), exact mod-N twiddles in long double.
- primelib2.py: component-phased symmetric prime DFTs (13/17/23) with register-budgeted
                k-splits (j-outer accumulation, hoisted register constants).
- gen.py      : SoA-8 batch-lane engine (8 volumes in zmm lanes; x-pass + per-plane y/z;
                elementwise map fused into the x-pass stores for most sizes), hybrid
                batch dispatch, map emitters (hw-sqrt + rcp14-NR / rsqrt14-NR alternation).
- genvol.py   : per-volume engine (padded split re/im rows; vertical y/x passes; z-pass
                via in-register 8x8 transposes; used for L=64 and batch remainders).
- gen64z.py   : L=64 row-wise z-codelet (radix-8 stage A vertical on row vectors, lane
                twiddle tables, single in-register transpose, stage B vertical).
