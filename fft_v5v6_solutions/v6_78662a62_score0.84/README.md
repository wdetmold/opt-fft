## Algorithm

Fully-unrolled AVX-512 codelets per size with all twiddles baked as
compile-time literals: Good–Thomas PFA (6=2x3, 36=4x9, 45=9x5), Cooley–Tukey
8x8 with a one-transpose "chunk-lane" z-pass for 64, and symmetric
half-length real-coefficient prime DFTs for 13/17/23 (register-tiled T=4,
staged through aligned scratch to kill spills). Two data layouts are merged:
codegen.py's interleaved complex layout with 4-complex-per-zmm codelets
(kept for 17/36 where it measured faster) and codegen_split.py's split
re/im-plane layout (shuffle-free complex arithmetic — Ice Lake port-5
relief) for the rest, plus an 8-volumes-in-SIMD-lanes AoSoA path for L<=13
(zero shuffles, zero lane waste; remainders of >=5 volumes run with dummy
lanes). Each volume iterates m steps resident in 2MB-hugepage scratch with
padded slab pitches (defeats 64KiB power-of-2-stride cache-set/TLB
pathologies); the x-pass uses T1 software prefetch 128 doubles ahead for
L>=36. The nonlinear map x <- z/(1+|z|) is fused into the last FFT pass and
batched 8 outputs at a time for ILP: rsqrt14 + one Newton step + a
self-correction to full double precision, reciprocal via rcp14+2 Newton for
small sizes and a mixed div/Newton scheme (alternating outputs) for L>=36 —
for those sizes as a two-phase pass (store z raw, then a dense L1-hot map
sweep); a 1e-280 clamp keeps zero pad lanes from triggering denormal
assists. Single-threaded, no FFT library anywhere in the graded path.
