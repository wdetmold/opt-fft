## Algorithm summary

All FFT arithmetic is hand-written AVX-512 (fp64, split re/im planes),
specialized per size at compile time via macro-instantiated "cores" that read
strided rows and write outputs through a fused store macro. Composite sizes
use twiddle-free prime-factor algorithms (6=3x2, 36=4x9, 45=9x5; DFT9 as
Cooley-Tukey 3x3) plus a direct radix-8 codelet and a CT(8,8) kernel with
long-double-accurate twiddles for 64; the primes 13/17/23 use symmetric
half-matrix kernels (fold x_j +/- x_{L-j}, then pure-FMA j-outer/k-inner
register-resident sweeps). Two execution modes: for L <= 23 a batch mode maps
the 8 SIMD lanes to 8 volumes of the batch in an interleaved, per-slice-padded
group layout (GS = L*L*8+8) — zero shuffles, zero masks, all three axis passes
in place with the Y and Z passes fused per x-slice; for 36/45/64 (and small-B
remainders) a slab mode runs an in-place strided axis-1 pass then a fused
axis-2 + axis-3 pass per slab in which only the contiguous axis needs 8x8
register transposes, writing output with axes 2/3 swapped so the orientation
alternates each iteration (the constant c is kept in both orientations). The
nonlinear map z/(1+|z|) is fused into the final pass using hardware vsqrtpd
(hidden on the otherwise-idle divider pipe) plus rcp14 with two Newton steps;
conversions are fully vectorized vpermt2pd interleaves/transposes; buffers are
2MB-aligned, MADV_HUGEPAGE-advised, and cache-set staggered; software
prefetching covers the strided row walks; an m==1 fast path memcpys the
one-step output. Accuracy measured in-session: one-step blocks ~2.4-6.6e-16
vs the long-double reference (15-40x under the 1e-14 gate).
