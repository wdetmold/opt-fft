## Algorithm (one paragraph)

Per-size specialized single-threaded AVX-512 kernels on interleaved
complex128, machine-generated by `gen.py` with all twiddles/coefficients as
compile-time hex literals rounded from long double: L=6 uses a twiddle-free
PFA 3x2 and L=8 a radix-2 kernel, fully inlined; the primes 13/17/23 use a
symmetric half-matrix real-coefficient direct DFT (cos/sin dot products), with
23 additionally getting 4-column GEMM-style multi-chunk variants
(`MULTI_PRIMES = {23}`); L=36 is a twiddle-free PFA 4x9 and L=45 a PFA 9x5;
L=64 is an 8x8 Cooley–Tukey whose x-axis runs as two in-place half-sweeps over
8-plane groups with an alternating digit-swapped plane layout (hugepage-backed
buffers) and whose z-axis is a lane-transposed in-register kernel with no
driver transposes. Each batch volume is iterated through all m steps while
cache-resident; the nonlinear map z/(1+|z|)+c is computed in fp64 by a
sqrt/rsqrt14+Newton hybrid plus a Montgomery batch inversion (one vdivpd per 8
vectors) and is software-pipelined into the final FFT pass of each step
(zipped one chunk behind for small/prime sizes, fused into the streaming pass
for 64), in batched 8-vector groups (the v14 "batchmap" refinement).
