# Exemplars — code kept from past panel rounds

Each subdirectory is one panel round. It holds the implementations judged worth showing
the next panel, each with the strategy record that explains it and the measured numbers
that justify it, plus a `NOTES.md` saying what the round established.

This is deliberately a curated set, not an archive: `bench/geom/impl/` is scratch and is
rewritten every round. The selection criteria are in `../../../docs/CURATION.md`.

Read these before writing a new implementation for the same geometry. An approach already
tried and measured here does not need trying again — the record says what it cost.
