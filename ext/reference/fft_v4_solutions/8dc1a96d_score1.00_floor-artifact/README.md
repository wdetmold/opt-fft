## Algorithm summary

Per size L ∈ {6,8,13,17,23,36,45,64}, fully specialized split-complex AVX-512
pipelines for the iteration z = FFT3(x) + c, x ← z/(1+|z|): FFT kernels
generated at development time (Cooley–Tukey 8=2×4, 64=8×8; Good–Thomas
prime-factor 6=2×3, 36=4×9, 45=9×5; even/odd-folded direct DFTs for primes
13/17/23 with loop-blocked embedded-broadcast constant tables, zero-padded to
kill an OOB-read denormal-assist bug). Three passes per iteration — z-lines via
in-register 8×8 transposes, y-lines, x-lines fused with +c and the nonlinear
map (rsqrt14 + 2 Newton steps + one vdivpd via s = r/(1+r)). Small sizes
(L ≤ 23) run an 8-volume lane-major batched pipeline (no transposes/masks in
steady state, per-L remainder thresholds, fused z+y slab pass); 36/45/64 use
stream-tiled two-stage x-passes plus a per-plane pz+py schedule for 64. First
iteration fuses the deinterleave of x0; final iteration fuses interleaved
output stores; m=1 aliases the two output blocks. State lives in one
MADV_HUGEPAGE mmap arena with plane strides and 1KB-mod-4K skews tuned against
4K aliasing; twiddles/tables are hex-exact compile-time constants.
