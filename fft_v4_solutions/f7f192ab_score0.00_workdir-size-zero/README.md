## Algorithm summary

A single self-contained AVX-512 C file, machine-generated by a Python emitter that
numerically verifies every emitted kernel against the exact DFT matrix during
generation. Per size: L=6 uses a twiddle-free PFA 2x3 and L=8 a radix-2^3, both run in
an AoSoA-4 layout (4 volumes interleaved per zmm lane — no transposes, no masked tails);
the primes 13/17/23 use a symmetric "half-matrix" direct DFT (cos/sin symmetry halves
the work, embedded-broadcast FMA accumulation), also AoSoA-4 with a per-volume `run1_L`
fallback for batch remainders; L=36 (6x6), L=45 (9x5) and L=64 (8x8) split the x-axis
into two radix stages fused across slice groups ("xsplit"), with in-place parity
(digit-reversed) iterations for the symmetric splits and buffer rotation for 45; L=64
additionally uses row+slice padding (row stride 68, slice pad 16 complex) to kill
64 KB/1 KB cache-set aliasing, a fused copy-in z-kernel (`kZ_64X`) on iteration 1, and
non-temporal streaming stores for final/one-step outputs. The elementwise map
z/(1+|z|) is computed pair-packed with `vrsqrt14pd`+Newton+Heron and `vrcp14pd`+Newton
(~0.5 ulp, no vsqrt/vdiv), fused into the last FFT pass. `run_size` sets FTZ/DAZ
defensively and restores MXCSR. All precomputation (long-double trig tables, work
buffers) happens in `initlib()` at import time.
