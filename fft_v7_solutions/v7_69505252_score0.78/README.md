## Approach

A ~4.8 MB machine-generated AVX-512 C file with all transform arithmetic
hand-built: Good–Thomas PFA 2x3 / 4x9 / 9x5 for L=6/36/45 (coprime factors,
zero twiddles), a radix-2 DIT codelet for L=8, 8x8 Cooley–Tukey with
longdouble-baked twiddles for L=64, and symmetric half-split ("Hartley-split")
direct DFTs for the primes 13/17/23 with per-prime accumulator-blocking
variants. Two execution strategies dispatched at runtime: a volume-interleaved
group path for L=6–23 (8 volumes per zmm in SoA, no shuffles, per-size
group-threshold `GTH_L` with 3-pass fallbacks for batch remainders), and for
L=36/45/64 a pipelined one-sweep-per-iteration schedule that fuses lag-axis
FFT → +c → nonlinear map (+one-step snapshot) → next-iteration same-axis FFT
per line, with the in-plane axis done via 8x8 in-register transposes.
Micro-architecture work: padded row/slab strides against L1 set-aliasing,
huge-page buffers, plane-ahead T1 prefetch, FTZ/DAZ, benign pad values to
avoid denormal assists, and the map z/(1+|z|) computed in-register as
rsqrt14+Newton plus port-balanced reciprocal refinement (~1 ulp; `NMODE=mix`).
