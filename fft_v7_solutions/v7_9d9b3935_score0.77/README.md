## Approach (from the attempt's own final summary)

AVX-512 split re/im straight-line FFT codelets per size — prime-factor
(Good–Thomas) for 6/36/45, mixed-radix Cooley–Tukey for 8/64, Rader with the
pointwise multiply fused into the inverse transform for 13/17/23 — selected
by an FMA-aware op-count search, constants generated at 160-bit precision
(mpmath), staged block emission keeping register liveness bounded. Each step
runs a y-pass with SIMD lanes across contiguous z (padded strides against L1
set-aliasing), a z-pass through in-register 8×8 transposes that swap the
volume orientation, and an x-pass blocked into two L2-resident plane-group
stages (36/64 via a self-inverse digit-reversed plane permutation, 45 via
alternating 5×9/9×5 factorizations, all in place) fused with `+c` and the
magnitude map (Newton from `rsqrt14` for |z|, hardware divide for the
reciprocal, full double accuracy). Stage 2 of step *t* feeds step *t+1*'s
plane work while each plane group is hot in L2; the state alternates
orientation between steps with `c` pre-stored in both layouts. Input
generation is a bit-exact C clone of numpy's `Generator(PCG64).standard_normal`
(PCG64 with 4-way jump-ahead + branch-light ziggurat, ~3.5 ns/sample vs
numpy's ~13), validated element-exact at import with a numpy fallback.
